# ReadDeck

ReadDeck is a local-first, static read-it-later PWA designed for GitHub Pages, Cloudflare Pages, or any other static host. Saved pages live in the browser's IndexedDB rather than on the host.

## MVP features

- import saved HTML pages, including SingleFile exports
- clean local reader view with basic clutter removal
- title/site/author metadata extraction
- local full-text search
- tags
- archive/unarchive and delete
- offline app shell through a service worker
- export the current article as standalone HTML
- print / save as PDF through the browser
- portable `.readdeck` backup and restore
- browser-extension capture contract for authenticated pages

## Privacy model

The host serves only static application files. Article content, tags, and metadata are stored locally in IndexedDB. No website passwords, cookies, or session tokens are stored by ReadDeck.

For authenticated/member-only pages, the planned browser extension will capture the already-rendered page in the active tab, rather than asking ReadDeck to log in to the source website.

## Run locally

Because service workers require HTTP(S), serve the folder rather than opening `index.html` directly. For example:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Static deployment

No build step is required. Point GitHub Pages or another static host at the repository root.

For GitHub Pages on a project repository, the manifest and service worker use relative paths so the app can run under `/readdeck/`.

## Backup

`Backup & restore` can download a `.readdeck` JSON backup containing all locally stored pages and metadata. Restore replaces the current device library after confirmation.

Google Drive `appDataFolder` backup is intentionally the next integration rather than part of the first commit. It will use OAuth in the browser and must not require a client secret in the repository.

## Browser capture

See [`extension/README.md`](extension/README.md) for the direct authenticated-page capture design. The MVP can already import HTML generated by SingleFile or another browser saver.

## Security notes

Imported HTML is sanitized before display: scripts, forms, embedded frames/objects, inline event handlers, and `javascript:` links are removed. Treat backups as private if they contain pages from authenticated services.
